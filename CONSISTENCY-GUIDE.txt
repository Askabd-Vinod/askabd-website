MODAL CONSISTENCY WITH SITE ANIMATIONS
========================================

Your website uses a beautiful scroll-reveal animation system.
Now the modal will use THE EXACT SAME animations!

========================================
ANIMATION CONSISTENCY:
========================================

✅ SAME TIMING
   - 80ms stagger between items (matching main.js)
   - 0.6s transition duration
   - cubic-bezier(0.22, 1, 0.36, 1) easing

✅ SAME EFFECTS
   - translateY(36px) → translateY(0)
   - opacity: 0 → opacity: 1
   - Same threshold (0.12)
   - Same rootMargin

✅ SAME INTERACTION OBSERVER
   - Modal uses IntersectionObserver
   - Same settings as your main site
   - Elements reveal as you scroll

✅ SAME HOVER EFFECTS
   - translateY(-8px) on stat cards
   - translateX(8px) on list items
   - Matches srv-card hover style

========================================
WHAT MATCHES YOUR SITE:
========================================

  - opacity 0.6s cubic-bezier(0.22, 1, 0.36, 1)
  - transform 0.6s cubic-bezier(0.22, 1, 0.36, 1)

MODAL NOW USES:
