================================================================
📋 SIMPLE 2-BRANCH WORKFLOW (Dev → Production)
================================================================

You have ONLY 2 branches:
  1️⃣ Dev  (for testing)
  2️⃣ main (live production site)

================================================================
🔄 COMPLETE WORKFLOW:
================================================================

STEP 1: MAKE CHANGES LOCALLY
-----------------------------
Edit files on your computer:
  - services.html
  - js/main.js
  - etc.

STEP 2: TEST ON DEV
--------------------
Run: 1-PUSH-TO-DEV.bat

This will:
  ✅ Switch to Dev branch
  ✅ Add your changes
  ✅ Commit them
  ✅ Push to Dev branch
  
Then:
  ✅ Wait 1-2 minutes
  ✅ Test on Dev URL
  ✅ Make sure everything works

STEP 3: GO LIVE (PRODUCTION)
-----------------------------
When Dev looks good, run: 2-PUSH-TO-PROD.bat

This will:
  ✅ Switch to main branch
  ✅ Merge Dev into main
  ✅ Push to main (Production)
  ✅ Your site goes LIVE!

================================================================
🎯 SIMPLE SUMMARY:
================================================================

Local Changes → Dev (test) → main (live)

That's it! Only 2 branches, simple workflow.

================================================================
📁 FILES FOR E-COMMERCE MODAL:
