## 🚀 How It Works

### User Journey:
1. User visits **askabd.com/services.html**
2. Sees service cards grid
3. Clicks **E-Commerce Development** card (has `data-service="ecommerce"`)
4. Modal smoothly opens with overlay
5. User scrolls through Problems → Solutions → Guarantees
6. Clicks CTA button → Goes to contact page

### Technical:
- Modal is hidden by default (`display: none`)
- JavaScript listens for click on `[data-service="ecommerce"]`
- Adds `.active` class → shows modal
- Close on: X button, overlay click, or ESC key
- Body scroll disabled when modal open
